# Batch File Zipper

</div>

A **lightweight, fully offline** tool for **batch compressing files and folders** into individual archives, with optional password protection for each one.

---

## Features

- **Batch compression** of unlimited files and folders in one operation
- **One archive per item**: every file, or every folder with its full contents
- **Drag & drop** import of files and folders
- **Optional password protection** with AES-256 encryption and a unique random password per archive
- **Password report** saved automatically as a CSV file
- **ZIP and RAR** output
- **Safe by design**: existing archives are never overwritten, originals are only deleted if you ask for it
- **Instant cancel** at any time, incomplete archives are cleaned up
- **Responsive interface**, works with hundreds or thousands of items

---

## Supported Formats

| Archive | Tools needed |
|---|---|
| ZIP without password | None (built-in) |
| ZIP with password | WinRAR or 7-Zip |
| RAR, with or without password | WinRAR |

---

## How to Use

1. Download the latest version from the [Releases](../../releases) page and run ABFZ
2. Choose **Select Files** or **Select Folders**, then add items by button or drag & drop
3. Set an **output path**, or leave it empty to place archives next to the originals
4. Optionally enable **password protection** and choose the archive format
5. Click **Start Compression**. Done!

Passwords, if enabled, are listed in the generated CSV file.

---

## System Requirements

**Windows 10 / Windows 11**. WinRAR and/or 7-Zip are optional, for password-protected ZIP and RAR archives.

---

## Privacy

ABFZ runs entirely offline. It collects no data and sends nothing anywhere. Your files never leave your machine.
